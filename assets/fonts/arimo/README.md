# Arimo UI font

Unmodified TTF files from the official Google Fonts Arimo project:
https://github.com/googlefonts/Arimo/tree/main/fonts/ttf

Bundled for offline Web rendering as `NoteFlowSans`; native keeps its existing
system typeface. The Web reference uses an Arial/Segoe-compatible system stack.
Measured sample at40px/700: Notion text advance655.625px, installed Chrome
Arial653.535px/Segoe UI654.336px; the previous fallback was substantially narrower.
Bundling avoids depending on operating-system fonts or a runtime font download.
